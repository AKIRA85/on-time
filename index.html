Troubleshooting

🔒 "Your organization has restricted this app"

If you're using a corporate Google Workspace account, your organization's IT administrator may have restricted access to third-party apps or the Google Calendar API.

For Users:

  • Try using a personal Google account (@gmail.com) instead
  • Contact your IT administrator and share the information below

For IT Administrators:

To enable this extension for your organization:

  1. Allow the Chrome Extension:
    Go to Admin Console → Devices → Chrome → Apps & extensions and add "On Time - Meeting Launcher" from the Chrome Web Store.
  2. Enable API Access:
    Go to Admin Console → Security → API Controls → App Access Control and add the OAuth Client ID:
    792189130460-ocgob7va4iu294139labq29rvrtd0est.apps.googleusercontent.com
  3. Grant Trusted Access:
    Mark the app as "Trusted" to allow the calendar.events.readonly scope.
